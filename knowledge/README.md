# Knowledge base (reference — not a copy of policies)

This folder holds **depth material**: promoted lessons, theory snapshots, failure patterns, and indexes. **Core principles** live in **`docs/principles/README.md`**; **enforceable contracts** live in **`docs/policies/`**.

| File | Purpose |
|------|---------|
| [`ide_lessons.md`](ide_lessons.md) | Promoted IDE/session lessons (append-only) |
| [`failure_patterns.md`](failure_patterns.md) | Recurring failure modes and mitigations |
| [`theory_snapshot.md`](theory_snapshot.md) | Short theory notes (non-normative) |
| [`open_questions.md`](open_questions.md) | Research questions not yet closed |
| [`evidence_index.json`](evidence_index.json) | Machine-readable index (if used by tooling) |
| [`decision_log.jsonl`](decision_log.jsonl) | Optional decision log |

**Adding content:** Prefer a **one-line summary** in `docs/principles/README.md` (or the relevant policy) and a **link** here for the full write-up.
