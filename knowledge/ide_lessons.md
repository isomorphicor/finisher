# IDE execution lessons (promoted from sessions)

**Purpose:** High-signal, **reviewed** findings from `run_ide_execution_agent` / session `project/` work that should inform **future** runs—without duplicating everything in `out/`.

**Not** a dump of every `execution_report.md`. **Not** a substitute for `docs/reference/quant_tech_stack.md` or skills; this file records **project-specific confirmations, caveats, or deltas** once they are stable enough to reuse.

## How entries get here

See **`docs/reference/agent_knowledge_system.md` → IDE execution → knowledge promotion** and **`docs/templates/knowledge_promotion_checklist.md`**.

## Entry template (append new lessons at the top under “Lessons”)

```markdown
### YYYY-MM-DD — <project>/<session> — <short id>

- **Source evidence:** `out/<p>/<id>/project/outputs/execution_report.md` (and key scripts under `project/src/` if any).
- **Context:** one sentence (data regime, mandate, model family).
- **Lesson:** what we believe now (falsifiable).
- **Relation to baseline:** `aligns` | `extends` | `exception` vs repo defaults (`quant_tech_stack`, `ide_agent` baseline contract).
- **Promotion gate:** metric or reproducibility note (why this is not a one-off).
- **Status:** `provisional` | `stable` | `superseded by <id>`.
```
